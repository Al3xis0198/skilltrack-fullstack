# SkillTrack 🚀

SkillTrack is a fullstack web application designed to help users track their learning progress and skills development.

---

## 🔧 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: PostgreSQL
- Version Control: Git & GitHub

---

## 🎯 Features (MVP)
- User registration and login
- Skill creation and management
- Progress tracking
- Dashboard view
